#
# ── 语法速查 ────────────────────────────────────────────────────
#   关键词              标题包含即匹配
#   /正则/              正则匹配，用 | 分隔多个词，默认忽略大小写
#   关键词 => 别名       指定显示名称
#   [组别名]            写在词组第一行，给整组命名
#   +关键词             必须词：所有必须词都命中才算匹配
#   !关键词             排除词：命中则排除该条新闻（仅当前词组内生效）
#   @数字               限制该词组最多展示多少条
#
# ── 三条硬规则 ──────────────────────────────────────────────────
#   1. 词组之间必须用「空行」分隔；同一词组内的多个词是「或」的关系
#   2. 匹配对象是新闻【标题】，不是正文
#   3. 本文件顺序不影响推送顺序：config.yaml 里 sort_by_position_first: false
#      表示按命中条数排序；改成 true 则按本文件先后顺序
#
# ── 调优提示 ────────────────────────────────────────────────────
#   · 推送太吵：给某组末尾加一行 @5（最多显示 5 条）
#   · 某个词误伤：在该组内加一行 !误伤词
#   · 想临时停用某组：把整组用空行隔开并注释掉即可
#
# ═══════════════════════════════════════════════════════════════
